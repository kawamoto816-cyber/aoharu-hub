# 過去問チャレンジ（/learn/kakomon）

共通テストの過去問を、生徒が大学入試センターの問題で解き、当サイトではマークシートの入力と採点だけをするページ。

## きまり

- **問題は載せない。** 問題文・選択肢の文・本文・図は、リポジトリにも画面にも入れない。持つのは、解答番号（解答記号）・正解・配点（大学入試センターが公表している正解の表）と大問の区切りだけ（`lib/kakomon/exams.json`）。
- 解説は出さない。正誤と正解まで。見直しのあとは、同じ科目の共通テスト模試（オリジナルの問題）へ案内する。
- 出典を、はじめ方と結果の画面に書く（大学入試センターウェブサイトの正解のページの URL と、アオハルOSが採点のしくみを作ったこと）。
- リンクは、リンク先が大学入試センターのサイトだと分かる文言にする（「問題のPDFを開く（大学入試センター）」）。

## 大学入試センターへの確認

- 2026-11-24 代表がセンターに確認し OK：①過去問のページ（問題の PDF・音声）へリンクしてよい　②正解の番号と配点を載せて採点に使ってよい。→ `DNC_LINK_OK = true`、検索にも出す（サイトマップに一覧と各試験）。
- センターの利用ルール（「このウェブサイトについて」）：試験問題の二次利用（複写・配布・問題集の作成）は申請が要る。問題を載せないのはこのため。

## 入っている試験（112）

令和8・7年度（本試験・追・再試験）：国語、地理総合・地理探究、歴史総合・日本史探究、歴史総合・世界史探究、公共・倫理、公共・政治経済、数学Ⅰ・A、数学Ⅱ・B・C、物理基礎・化学基礎・生物基礎・地学基礎、物理・化学・生物・地学、英語リーディング・リスニング、情報Ⅰ（各19）。
令和6年度（旧課程・本試験・追・再試験）：国語、世界史B、日本史B、現代社会、倫理、政治・経済、倫理・政治経済、物理基礎・化学基礎・生物基礎・地学基礎、物理・化学・生物・地学、英語リーディング・リスニング（各18）。
入れていないもの：令和6年度の数学（式で答える旧い形）、地理B（令和6）、地理総合／歴史総合／公共、A科目・簿記・情報関係基礎・旧課程の令和7年度の科目、ドイツ語などの外国語。

- 基礎の科目は1科目30分・50点で出す（本番は2科目60分。画面に書いた）。
- 数学Ⅱ・B・C は第4〜7問から3問選択。4問マークしたら得点の高い3問を数える。
- 令和7年度の化学は新課程の第1〜5問だけ（旧課程の選択の第6問は入れていない）。

## 正解の読み取り方（2026-11-24）

1. 大学入試センターの「正解」の PDF を、アプリ内ブラウザで pdf.js で描き、**表の罫線（画像）からセルを割り出し、文字の位置でセルに入れた**（`scripts/kakomon/` の説明どおり）。セルの結びつき（＊の組・各○点・順を問わない）は罫線で決まる。
2. 罫線の読み取りがずれた表（基礎科目の3つ目の表など）は、2回目の読み取り（`scripts/kakomon/pass2.txt`）で入れ直した。
3. 注（＊）の特別な採点は、PDF を画像で見て手で入れた（`scripts/kakomon/build.py` の後半）：
   - 「1又は2」と、それに応じて決まる次の答え：令和8本 日本史16-17・政経9-10/21-22、令和7本 倫理27-28、令和7追 倫理27-28、令和6本 世界史B 13→14
   - 前の記号が正解のときだけ点：令和8本 数ⅡBC 第5問ク・ケ、令和7本 数ⅠA 第2問シ・ト／第4問ス・セ・ツ・テ、令和7本 数ⅡBC 第5問チ・ツ
   - 部分点：令和8本 生物23、令和8追 生物基礎117、令和7本 生物基礎106・116、令和7本 生物21・23、令和7追 生物13・20、令和6本 生物2・7・10・12・13-14、令和6追 生物5
4. 検算：`npx tsx scripts/check-kakomon.ts`（大問の配点の合計＝公表の配点、満点、解答番号の並び、正解が選択肢にあるか、全問正解で満点・白紙で0点、採点のきまり14例）。PDF のリンク先は14件を開いて科目が合うことを確かめた。

`scripts/kakomon/build.py` は、ブラウザで読み取った raw.json（リポジトリには入れていない）から exams.json を作るスクリプト。年度が増えたら同じ手順で足す。

## 作り

| 場所 | 内容 |
|---|---|
| `lib/kakomon/types.ts` | データの形（順を問わない・全部そろって正解・各○点・又は・別の欄で決まる・部分点・前の記号が条件・選択問題） |
| `lib/kakomon/exams.json`・`data.ts` | 112試験の正解・配点・問題の PDF・音声のリンク |

| `components/kakomon/Challenge.tsx` | マークシート（時計つき・時間で自動提出・途中は端末に保存）→ 結果 |
| `app/learn/kakomon/`・`[id]/` | 一覧（えらぶ画面）と各試験。`?start=1` で開くとすぐに時計が動く |
