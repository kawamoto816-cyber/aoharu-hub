# 過去問チャレンジ（/learn/kakomon）

共通テストの過去問を、生徒が手元の問題で解き、当サイトではマークシートの入力と採点だけをするページ。2026-11-24 に代表のOKで作成。

## きまり

- **問題は載せない。** 問題文・選択肢の文・本文・図は、リポジトリにも画面にも入れない。持つのは、解答番号・正解の番号・配点（数値の表）と大問の区切りだけ（`lib/kakomon/data.ts`）。
- 解説は出さない（解説を書くと問題文を引くことになる）。正誤と正解の番号まで。見直しのあとは、同じ形の共通テスト模試（オリジナルの問題）へ案内する。
- 正解と配点の出典を、結果とはじめの画面に書く（大学入試センターウェブサイトの URL と、アオハルOSが作成したこと）。

## 大学入試センターの利用ルール（2026-11-24 に「このウェブサイトについて」で確認）

- 試験問題の二次利用（複写・配布・問題集の作成。インターネット上を含む）は、事前の申請と許諾が必要。→ だから問題は載せない。
- 試験問題に当たらないコンテンツは、出典を書けば商用でも使える。数値データ・簡単な表は著作権の対象ではなく自由に使える、とある。→ 正解の番号と配点はこの扱いと考えて持っている。**ただし、正解の表が「試験問題」に含まれないかは、センターに確かめていない。**
- リンクは原則自由だが、「リンクが営利目的に結びつくおそれがあるとき」は禁止。リンク先がセンターのサイトであることを明記し、サイトの一部に見える形は不可。→ 当サイトは有料の商品があるので、**確かめるまでリンクは置かない**（`DNC_LINK_OK = false`）。生徒には、センターのサイトか市販の過去問集で問題を用意してもらう。
- センターに確かめること（総合案内 03-3468-3311）：①過去問のページへリンクしてよいか　②正解の番号と配点を載せて採点に使ってよいか。OK が出たら `DNC_LINK_OK` を true にし、検索にも出す。

## 作り

| 場所 | 内容 |
|---|---|
| `lib/kakomon/types.ts` | データの形。順を問わない組・全部そろって正解・各○点 を表せる |
| `lib/kakomon/data.ts` | 試験ごとの正解と配点。いまは令和8年度 本試験 英語リーディングの1つ |
| `lib/kakomon/grade.ts` | 採点と、データの検算 |
| `scripts/check-kakomon.ts` | 検算（配点の合計・解答番号の並び・全問正解で満点・採点のきまり7例） |
| `components/kakomon/Challenge.tsx` | はじめ方 → マークシート（時計つき・時間で自動提出）→ 結果。途中はこの端末に保存 |
| `app/learn/kakomon/` | 一覧と各試験のページ。**noindex・サイトマップに入れていない** |

- 計測：`kakomon_start`・`kakomon_submit`（exam・score・auto）。
- 入口：共通テスト模試（/learn/kyotsu-moshi）の下の案内から。

## 試験を足すとき

1. センターの「正解」の表を見て `data.ts` に入れる（＊＝全部そろって正解、ハイフン＝順を問わない、各○点）。
2. `npx tsx scripts/check-kakomon.ts` がエラー0になること。
3. 数学は「ア・イ・ウ」のマスに数字・符号を入れる形なので、いまのマークシート（1〜9）では足りない。入力の形を足してから。
4. リスニングは音声が要る（センターのサイトで聞いてもらう形になる）。
