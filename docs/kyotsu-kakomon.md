# 共通テスト 過去問の出題分析（共通テスト模試の型の元）

- 読んだ資料：大学入試センター「過去3年分の試験問題」 https://www.dnc.ac.jp/kyotsu/kakomondai/ （令和6・7・8年度）。2026-11-24 に読んだ。
  - 正解・配点の表：令和6・7・8年度の本試験（全教科）。
  - 問題冊子：令和8年度と令和7年度の本試験（大問の頭の文・ページ数・分野）。
  - まだ読んでいない：追・再試験、令和6年度の問題冊子（旧課程）、各大問の小問ごとの型。
- きまり：**過去問の文章・設問・数値は写さない。** ここには大問の数・配点・分野・形式・分量だけを書く。問題はすべて新しく書く。過去問そのものはリポジトリに入れない。
- 令和7年度から新課程。大問の数と配点は、令和7・8年度でほぼ同じ。型は令和8年度に合わせた。

## 各科目の大問の分野（令和8年度。かっこ内は令和7年度）

- **数学Ⅱ・B・C**：第1〜3問は必答（R7：三角関数／指数・対数／微分・積分）。第4問 数列、第5問 統計的な推測、第6問 ベクトル、第7問 平面上の曲線と複素数平面 から3題を選ぶ。
- **物理基礎**：第1問 小問集合／第2問 力学の実験・探究（R7も力学の探究）／第3問 熱と電気（R7：比熱の測定）。
- **化学基礎**：第1問 小問集合（10問前後）／第2問 身近な題材の総合問題（3問）。
- **生物基礎**：第1問 生物の特徴と遺伝情報／第2問 ヒトのからだの調節／第3問 多様性と生態系。どれも文章A・B。
- **地学基礎**：第1問 固体地球・地球の歴史など（A〜C）／第2問 大気と海洋／第3問 宇宙／第4問 自然災害。
- **物理**：第1問 小問集合／第2問 力学（R7：波と探究）／第3問 熱（A・B）／第4問 電磁気。
- **化学**：第1問 物質の状態（理論）／第2問 エネルギー・速さ・平衡／第3問 無機／第4問 有機・高分子／第5問 身のまわりの物質の総合問題。
- **生物**：第1問 進化／第2問 細胞／第3問 発生／第4問 環境応答／第5問 生態（R7：感覚・代謝・生産・発生・植物の応答）。
- **地学**：第1問 分野をまたぐ総合問題／第2問 固体地球／第3問 地質（配点が最も大きい）／第4問 大気と海洋／第5問 宇宙。
- **地理総合・地理探究**：第1問 生活文化（地理総合）／第2問 地域調査（地理総合）／第3問 自然環境と自然災害／第4問 産業／第5問 人口と都市／第6問 地誌。
- **歴史総合・日本史探究**：第1問 歴史総合／第2問 時代をまたぐテーマ史／第3問 古代／第4問 中世／第5問 近世／第6問 近現代。
- **歴史総合・世界史探究**：第1問 歴史総合／第2〜5問は「法」「税」「都市」など、時代と地域をまたぐテーマで組まれる。
- **公共・倫理、公共・政治経済**：第1問・第2問は公共で、2科目に共通の問題。第3問からが倫理／政治・経済。どの大問も、生徒の会話や探究の場面から始まる。

## まだ公式と合っていないところ

- 数学Ⅱ・B・C の「4題から3題を選ぶ」は、模試では数列・統計・（ベクトル／曲線／複素数平面のどれか）に固定。
- 世界史は、公式はテーマで組むが、模試は時代ごと。
- リスニング第4問の「全部正解で点」の形、リーディングの順不同の解答は、模試では1問ずつの選択にしている。
- リスニング第2問のイラストの選択肢は無い（文字の選択肢）。
- 公共・倫理の第3〜6問、公共・政治経済の第3〜6問の分野の割りふりは、2年分の大問の頭の文からの見立て。
