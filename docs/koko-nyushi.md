# 公立高校入試の過去問チャレンジ（/learn/koko-nyushi）

公立高校入試の過去問を、生徒が教育委員会の公開ページの問題で解き、当サイトでは時間・自己採点・作戦表だけを出すページ。画面とデータの形は、2次試験の過去問チャレンジ（`lib/niji`・`components/niji/NijiChallenge.tsx`）をそのまま使う。

## きまり

- **問題は載せない。** 問題文・選択肢・本文・図・資料は、リポジトリにも画面にも入れない。設問の名前は、内容を短く言いかえたもの。
- 持つのは、正答（記号・数・語）と配点（教育委員会が公表している正答表）と、大問の区切り。
- **記述の解答例は、正答表のものを写さない。** 証明・作文・英作文・説明は、アオハルが書いたチェック表と解答例を出す（証明は数学の事実なので筋道は同じになる）。
- リンクは、その年度の掲載ページへ張る（PDF への直リンクはしない。差し替えで URL が変わるため）。
- 出題ミスで全員加点になった設問は、その旨を答えの欄に書き、○をつけてもらう（東京 令和8 理科 大問6 問3）。

## 入っている試験

- 東京都立高校 令和8年度（一次・分割前期）：国語・数学・英語・社会・理科（各50分・各100点）。`lib/koko/tokyo-2026.ts`
  - 正答表の PDF を画像で読み、配点の合計が各100点になることを `npx tsx scripts/check-niji.ts` で確かめた（2026-11-24）。
  - 単元は、設問の書き出しを読んで中学の単元（`j-…`）に当てた。国語の大問3〜5と英語の大問3・4は、設問ごとの細かい単元までは分けていない（小説・論説・古典・長文）。

## 作り

- `NijiExam` に足した項目：`base: "koko"`（入口と戻り先）、`pageOwner`（問題を出している所）、`pointsNote`（配点は公式、の注記）。
- 入口 `app/learn/koko-nyushi/page.tsx`、各試験 `app/learn/koko-nyushi/[id]/page.tsx`。試しの公開なので noindex、サイトマップにも入れていない。
- さかのぼりからの戻り：`KakomonReturn` の `base: "koko"`。
- **自動採点（2026-11-24）**：`NijiItem.sel`（えらぶ欄の並び。全部合えば正解）。記号1つ・組み合わせ・並べかえ・数字のマーク（あ・い…）は、えらぶと○×がつく。漢字・計算の答え・作図・英語で答える設問・記述は、自分で○×かチェック表。`lib/koko/tokyo-2026.ts` の `a()` が、答えの書き方（「エ」「① イ　② ア」「ウ → イ → ア → エ」）から欄を作る。
- **問われ方（2026-11-24）**：`NijiItem.skill`。国語の小説・論説、英語の長文は、単元が1つに集まるので、作戦表を「小説を読む：人物の様子・気持ち」のように問われ方でも分ける。行き先（単元模試・図解・さかのぼり）は単元のまま。
- 入口：「まなぶ」トップの模試の段（過去問チャレンジ3つ）、公立高校入試模試のページ、大学別模試のページ（2次試験）。

## 都道府県ごとの調査（2026-11-24）

47都道府県の公式サイトを調べた結果は、作業メモ `koko-nyushi-47.json`（リポジトリ外）にある。令和8年度の問題と正答が公式サイトにそろうのは21都府県。宮城はウェブでの利用に申請が必要と明記、長野・高知はトップページ以外へのリンクに問い合わせが必要、京都・福岡・大阪は転載禁止と明記（リンクを禁じる記述はない）。県を足す前に、その県の注意書きを読むこと。

問題と正答の PDF は、作業環境から県のサイトに直接つながらないので、代表のパソコンの Chrome で開いて保存したものを読んでいる（`~/Downloads/koko-nyushi/<県>-<年度>/`）。

## 解答用紙（2026-11-24）

- 公立高校入試（`exam.base === "koko"`）は、紙に解いて自己採点する形をやめ、画面の解答用紙に答えを入れてから採点する（じゅんさんの指示）。`NijiChallenge` の `A`。2次試験（/learn/niji）はもとのまま。
- えらぶ設問（`sel`）はマークと同じ：出したときに自動で ○×（答えていなければ ×）。語句・数（`ans` だけ）は入力欄：正答と合えば（全角・空白・かっこのちがいは見ない）自動で ○、空欄は ×、合わなければ採点の画面で見くらべて自分で ○×。記述（`steps`）は入力欄に書き、採点の画面で自分の答えを見ながらチェック表をつける。
- 作図などは `paper: true`（`a()` が名前から付ける）。解答用紙には入力欄を出さず、採点のときに ○× をつける。
- 「問題を開く」は、科目ごとの問題のPDF（`qPage`）を直接開く。出典の行（Source）は、もとの一覧ページのまま。
- 2次試験（/learn/niji）でも同じ解答用紙を使えるようにした（同日）。はじめ方で「画面の解答用紙に書く／紙に書く」をえらぶ。記述が中心の科目（style: kijutsu）は画面、数学・理科は紙がはじめの設定。えらんだ形は端末の記録（Saved.sheet）に残る。
- 採点の画面で、えらぶ設問の ○× の下に「正解と理由」を出す（`NijiItem.why`。2026-11-25）。記号だけでは学びにならない、というじゅんさんの指摘。中身は `lib/koko/tokyo-2026-why.ts`（キーは「大問-設問」）。選択肢の写しではなく、正解が言っていることの要旨と根拠をアオハルの言葉で書く。英語は全21問を書いた。国語14・数学9・社会17・理科22 は、まだ。

## 青森県 令和8年度（2026-11-26）

- `lib/koko/aomori-2026.ts`。共通の部品は `lib/koko/make.ts`（ch・chs・order・tx・paper・wr・dai・kokoExam）。東京より後の県はこれで作る。えらぶ設問の why は、データの中にいっしょに書く。
- 正答と配点は県の「採点基準」PDF。国語の大問4・5は問題文が非公開なので入れていない（国語は52点分）。国語・英語の放送問題は、音声がないので県の「放送台本」PDFを読んで答える（timeNote に書いた）。
- 数学の作図と、数学・理科のグラフをかく設問は paper（紙にかいて自己採点）。
- 進め方の計画は作業メモ（_jugyo-tools/koko-plan.md）。平日13時に1県ずつ。

## 神奈川県 令和8年度（2026-11-26）

- `lib/koko/kanagawa-2026.ts`。共通選抜（全日制・2月17日）の数学・英語・理科・社会。マークシート方式なので、英作文1問以外はすべて自動採点。数字をマークする欄は `marks()`（make.ts）。
- 国語は、問二・問三の本文が著作権の都合で公開されていないので、まだ入れていない（問一・問四・問五だけで作るかは、あとで決める）。
- 二次利用のきまり：事前の承認は不要。出典に「神奈川県の著作物」と書いた（pageLabel）。公開した日から1か月以内に、e-kanagawa の「学力検査問題等の二次利用報告フォーム」で報告する（報告はじゅんさんの「送信して」で）。
- リスニングの音声は県のページで公開されている（MP3）。こちらには置かず、timeNote で案内する。
- 長文の読み取りのうち、根拠をたしかめきれなかった設問（英語の問6・問7・問8アと、社会の問7エ）には「正解と理由」を付けていない。
