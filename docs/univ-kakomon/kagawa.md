# 香川大学 過去問の出題分析（類似問題づくりの元）

- 読んだ資料：大学公式「一般選抜 過去問題」 https://www.kagawa-u.ac.jp/admission/entrance_exam/past_exam/general/ の 2026年度（掲載は 2027-06-30 まで。載っているのはこの1年分だけ）。
- 読み方：PDF はスキャン画像なので、アプリ内ブラウザでページを画像にして目で読んだ（2026-11-24）。
- きまり：**過去問の文章・設問・数値は写さない。** ここには形式・分野・設問の型・分量だけを書く。類似問題は、この分析をもとに新しく書く。過去問そのものはリポジトリに入れない。

## 外国語（英語）　90分・大問3題・全学部共通（問題冊子8ページ）

英文の本文は、公式の掲載では著作権のため伏せられている（出典の表示だけある）。

| 大問 | 素材 | 分量 | 設問 |
|---|---|---|---|
| Ⅰ | 英字新聞の科学記事（研究者が行った調査・実験を紹介する文章。身近な題材）。語注1つ | 本文 約3ページ | **英問英答 10問**。指示は「英語の文で答える（1問だけ例を挙げる形で、文でなくてよい）」。問いは本文の順で、研究の問い／例を2つ挙げる／実験での人々の反応／判断に使ったもの／ある行動が起きる条件／実験でいちばん興味深い結果／追跡研究が示したこと／両者の協力のしかた／得意なこと／注意深く見ると何が学べるか。**事実を本文から拾って1〜2文で書く問いが中心** |
| Ⅱ | 筆者の体験と考えを語るエッセイ（下線①〜⑩と空所つき） | 本文 約2ページ | **日本語で答える 10問**（うち2問は別形式）。内訳：理由の説明×2（「なぜ筆者はそのような気分になるのか」「なぜこの行動をとるのか」）／**語句整序 1問（7語を並べかえて空所を埋める）**／指示語の内容×1（this）／**下線部和訳×1**／**空所に入る英単語1語**×1／具体例の説明×1／得られる教訓の説明×1／筆者のどんな一面かの説明×1／語（抽象名詞）の指す内容×1 |
| Ⅲ | グラフ（国別の割合を比べる棒グラフ。統計サイトの図） | 図1つ | **英作文 約120語**。a. グラフから何が分かるか　b. 関連する問いへの自分の意見と理由。**a と b の両方に答えて合計約120語** |

読み取れる特徴
- 大問Ⅰは「英語で答える」、大問Ⅱは「日本語で答える」と、答える言語がはっきり分かれている。選択肢の問題はない。
- 設問は各10問と多く、1問あたりは短い記述。本文の該当箇所を正確に拾えるかを見る。
- 大問Ⅱは和訳・整序・空所1語が1問ずつ入り、文法・語彙の力も見る。
- 大問Ⅲは「資料の説明＋意見」の2部構成。語数は合計で指定。

## 数学　90分・記述式（答えに至る過程を書く）

| 区分 | 大問 | 解き方 |
|---|---|---|
| 教育学部・医学部臨床心理学科・農学部 | 5題 | 〔1〕〔2〕〔3〕必答、〔4〕〔5〕から1題選択 → 4題を解答 |
| 創造工学部Aタイプ | 4題 | 全問必答。〔1〕〔2〕〔3〕は上と同じ問題、〔4〕は上の〔5〕（数学Ⅲ）と同じ |
| 法学部・創造工学部Bタイプ／医学部医学科 | 別冊子 | まだ読んでいない |

| 大問 | 分野 | 小問の流れ |
|---|---|---|
| 〔1〕 | 図形と計量＋平面ベクトル | 3辺の長さが与えられた三角形。(1) 余弦定理で cos (2) 内積 (3) 辺上を動く点について、3つのベクトルの和の大きさの最小値（始点をそろえて1つのベクトルにまとめる） |
| 〔2〕 | 図形と方程式（2つの円） | 文字定数をふくむ円と定円。(1) 定数が特定の値のときの共有点の座標 (2) その2点と別の1点を通る円（円束の考え）(3) 共有点がちょうど1つ（接する）ときの定数の値 |
| 〔3〕 | 数列 | 逆数をとると解ける漸化式（等比数列の項が加わる形）。(1) 初めの数項 (2) 一般項 (3) 一般項から作る別の数列 (4) 隣り合う項を座標にした点がすべて一直線上にあることの証明 |
| 〔4〕選択（数学Ⅱ） | 微分・積分 | 2つの3次曲線が点を共有し共通の接線をもつ。(1) 定数の値 (2) 接線と曲線の別の共有点 (3) その点を通る別の接線 (4) 接線2本と曲線で囲まれた図形の面積 |
| 〔5〕選択（数学Ⅲ）＝Aタイプ〔4〕 | 微分・積分（対数関数） | y＝log x。(1) ある点での接線 (2) 軸・接線・曲線で囲まれた図形の面積 (3) それを y 軸のまわりに回転させた立体の体積 |

読み取れる特徴
- どの大問も (1)→(2)→(3) の誘導つきで、(1) は基本の確認。最後の小問で一段ひねる（最小値・接する条件・証明・回転体）。
- 小問集合や確率は、この年度のこの冊子には無かった（受験情報サイトの「確率・複素数平面」は、この冊子では確認できない）。
- 数学Ⅲをふくまない受験者は〔4〕、ふくむ受験者は〔5〕を選ぶ作りで、共通の3題＋選択1題。

## いまの「香川大学型」とのちがい（直すところ）
- 英語：いまは旧帝大の大問を流用した部品方式（長文2＋自由英作文）。→ **Ⅰ 英問英答10問／Ⅱ 日本語で答える10問（和訳・整序・空所1語をふくむ）／Ⅲ グラフの説明＋意見 約120語** に書き下ろす。
- 数学：型が無い。→ 文系範囲（〔1〕〔2〕〔3〕＋数学Ⅱの微積）と理系範囲（〔1〕〔2〕〔3〕＋数学Ⅲの微積）の2つを、上の分野と誘導の流れで書き下ろす。
